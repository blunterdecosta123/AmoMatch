# AmoMatch · Autonomous Agentic Dating Network 💘

> **Autonomous AI dating network where agents read people's public LinkedIn & Instagram, synthesize core needs & hobbies, date each other live in character, and rank who fits each person best.**  
*(Exactly 188 characters)*

---

## 🌟 The Core Idea

In **AmoMatch**, each real person is represented by an autonomous AI agent. That agent dates on that person's behalf. The agents date each other in rich, simulated multi-turn scenarios, evaluate authentic chemistry, and rank who fits each person best across the entire network.

For every person, and for every agent, there are **exactly two official sources of information**:
1. **The person's public LinkedIn profile** (Career, education, intellectual pursuits, communication tone, professional ethos)
2. **The person's public Instagram profile** (Visual aesthetics, weekend downtime, athletic & creative hobbies, lifestyle pace)

```
LinkedIn public profile  +  Instagram public profile
                     ↓
         The Agent Reads & Analyzes
     (Needs · Hobbies · Interests · Qualities)
                     ↓
               Profile Page
     (Inspectable analysis & agent persona)
                     ↓
             The Agents Date
        (Autonomous multi-turn dates)
                     ↓
             Rankings Matrix
        (Who fits each person best)
```

## 🎯 What's Inside & Verification

1. **26 Real People Verified Dataset**:
   - 26 real founders, creators, athletes, researchers, and designers.
   - Every single person has their **verified official LinkedIn URL** and **verified public Instagram URL**.
   - Fully scraped and analyzed into needs, hobbies, interests, and other qualities.
2. **Agent Profile Pages**:
   - Inspect any person's agent reading:
     - **Needs in a Partner** (emotional security, intellectual wavelength, pace of life)
     - **Hobbies & Downtime Habits** (music, pilot flying, tennis, ceramics, journaling)
     - **Interests & Curiosities** (AI frontiers, biotech, storytelling, Bauhaus architecture)
     - **Other Qualities** (banter style, energy level, communication cadence, love language)
     - **Radar Trait Gauges** (Ambition, Intellect, Spontaneity, Banter, Empathy, Creativity)
3. **The Autonomous Dating Arena (Watch Agents Date Live)**:
   - Real-time turn-by-turn dialogue generated in character between any two agents.
   - Choose thematic date venues (*Velvet Underground Vinyl Speakeasy*, *Third-Wave Roastery*, *Pacific Cliffside Observatory*, etc.).
   - **Internal Monologue Stream**: Toggle to see each agent's private thought stream during the date.
   - **Live Chemistry Meters**: Dynamic gauges for Intellectual Spark, Banter Rapport, Emotional Depth, and Values Alignment.
   - **Agent Debrief & Verdict**: Both agents write an honest post-date reflection and render a second-date decision.
4. **Individualized Rankings Matrix (Who Fits Each Person Best)**:
   - For **every single person** in the 26-person pool, generate an individualized ranking list from **#1 down to #25**.
   - Shows compatibility percentage, match tier (*Soulmate Tier*, *High Synergy*, etc.), and detailed rationale for why they fit.
   - One-click **"Watch Date"** button to jump straight into replaying their date simulation.
5. **Live "Add Person" Scraper**:
   - Paste any new person's name, public LinkedIn URL, and public Instagram URL.
   - Watch the agent scrape both sources, extract needs/hobbies/interests, synthesize their dating persona, and deploy them into the active dating pool.

## 🛠️ Technical Section: Scraping Stack & Agent Architecture

### 1. LinkedIn Scraping Stack
- **Apify Integration**: Official integration using `apify-client` and Apify Actors `curious_coder/linkedin-profile-scraper` and `anchor/linkedin-profile-enricher`. Extracts headline, job titles, companies, education, skills, and industry signals.
- **Resilient Fallback Engine**: Uses Cheerio, Jina Reader (`https://r.jina.ai/<url>`), and JSON-LD schema extractors to parse public profile data and metadata tokens cleanly without authentication barriers or IP rate limits.

### 2. Instagram Scraping Stack
- **Apify Integration**: Integration with Apify Actor `apify/instagram-profile-scraper` capturing public bio text, post captions, categories, hashtags, and visual lifestyle themes.
- **Resilient Fallback Engine**: Direct public profile JSON query (`?__a=1&__d=dis`) and OpenGraph metadata parser for instant zero-dependency data fetching.

### 3. Agent Synthesis & Reading Engine
- Synthesizes both sources:
  - **LinkedIn** informs the agent's ambition level, intellectual framework, and communication cadence.
  - **Instagram** informs the agent's aesthetic vibe, downtime habits, hobbies, and emotional openness.
- Generates structured schema:
  - `needs`: What the person needs in a partner
  - `hobbies`: Tactical downtime habits and sports
  - `interests`: Intellectual and philosophical curiosities
  - `otherQualities`: Banter style, energy level, communication tone
  - `traits`: Numerical vectors for Ambition, Intellect, Spontaneity, Banter, Empathy, Creativity.

### 4. Multi-Agent Dating Simulation Harness
- Autonomous turn-by-turn dialogue engine that places any two agents at a custom venue.
- Generates realistic, authentic conversation referencing their actual hobbies, experiences, and mutual questions.
- Tracks **inner monologues** revealing what each agent is thinking privately.
- Computes real-time dynamic chemistry scores (Intellectual Spark, Banter Rapport, Emotional Depth, Values Alignment).
- Generates post-date debriefs, ratings, and second-date decisions.

## 🚀 Quickstart Guide

### Prerequisites
- Node.js (v18+)
- npm

### 1. Clone & Install
```bash
git clone <your-repo-url>
cd ApifyHackathon
npm install
```

### 2. Configure Environment (Optional)
```bash
cp .env.example .env
```
*(You can leave `APIFY_API_TOKEN` blank to use the built-in resilient web scraper fallback, or provide your Apify API key for direct actor execution).*

### 3. Build & Run
```bash
# Build frontend assets
npm run build

# Start the full-stack server
npm start
```
Open **`http://localhost:3001`** in your browser.

For local frontend development with hot-reloading:
```bash
npm run dev
```
